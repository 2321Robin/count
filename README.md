# 捕捉计数器使用说明

这是一个按赛季记录精灵遭遇次数、当前轮次进度、正在抓目标、自己获得记录和别人赠送记录的网页计数器。S2 和 S3 的默认精灵、计数、当前轮次、获得历史、赠送记录、本地备份和同步文件相互隔离；现有 S2 记录会保留，S3 启用后会使用自己的默认精灵列表并从 0 开始。应用默认把数据保存在当前浏览器本地；不登录、不配置同步也可以正常使用。

在线地址：http://count.w2321.top/

## 快速开始

1. 在顶部确认当前赛季；S2 和 S3 数据分开保存，切换赛季不会删除其它赛季记录。
2. 打开网页后，在“当前轮次”里标记正在抓的精灵。
3. 在精灵列表中找到要刷的精灵，每遭遇一次点击对应精灵的 `+1`。
4. 点错时点击 `-1` 回退一次；本轮计数回到 0 的精灵会自动移出当前轮次。
5. 自己抓到目标后，点击该精灵的 `记录获得`，选择“中了！”，填写时间和备注后保存。
6. 如果抓当前目标时歪出其它精灵，点击歪出的精灵 `记录获得`，选择“歪的”保存；本轮计数不会改变。
7. 别人送给你的精灵，点击 `记录赠送` 单独记录。

## 页面区域

### 顶部操作

- `赛季`：切换当前操作的赛季。切换后会加载该赛季自己的精灵列表、当前轮次、统计和历史记录；主题和 GitHub Token/Gist ID 仍共用。
- `主题`：切换页面配色。默认是 `洛克幻想`，也可以选择 `深蓝夜航`、`霓虹赛季`、`森野薄荷`、`落日橙粉`、`纸白墨黑`。
- `新增精灵`：添加自定义精灵。

### 数据管理与多端同步

导入导出、本地重置和 GitHub Gist 多端同步已合并到同一个模块。默认只展开基础数据操作，同步配置可以按需展开；不配置也不会影响本地使用。所有数据操作都只影响当前选中的赛季。

本地数据操作：

- `导出 JSON`：下载当前赛季的完整数据备份。S2 文件名为 `s2-capture-counter-backup.json`，S3 文件名为 `s3-capture-counter-backup.json`。
- `导入 JSON`：把备份导入到当前选中的赛季。旧版数据会自动兼容并升级；导入不会覆盖其它赛季。
- `清空所有数据`：删除当前赛季的所有精灵和记录，操作前会确认；其它赛季不受影响。
- `重置默认数据`：恢复当前赛季的默认精灵列表并清空当前赛季记录，操作前会确认；其它赛季不受影响。

如果想在多台设备间同步，当前使用 GitHub 私密 Gist：

- `GitHub Token`：填写 GitHub Personal Access Token，只需要 `gist` 权限。Token 在 S2/S3 间共用。
- `Gist ID`：第一次上传可以留空；上传成功后会自动保存。Gist ID 在 S2/S3 间共用。
- 同步文件：同一个 Gist 可以同时保存多个赛季文件；S2 使用 `s2-capture-counter.json`，S3 使用 `s3-capture-counter.json`。
- 启动自动检查：保存 Token 和 Gist ID 后，打开页面会自动检查当前赛季的云端数据；如果当前赛季云端总抓取数更高，会自动应用云端版本。
- 本机保留规则：如果当前赛季本机总抓取数等于或高于云端，会保留本机版本。
- 自动上传：当前赛季本机数据变化后会在短暂延迟后自动上传到当前赛季的 Gist 文件。
- `上传本机数据`：立即把当前赛季数据上传到 Gist；如果 Gist ID 留空，可能会创建一个私密 Gist。手动上传仍会覆盖当前赛季的云端文件。
- `拉取云端数据`：手动比较当前赛季本机和云端总抓取数，并保留更高的版本。
- `退出同步`：清除本机保存的 Token 和 Gist ID，不会删除任何赛季的计数数据。

获取 GitHub Token 的步骤：

1. 登录 GitHub。
2. 点击右上角头像，进入 `Settings`。
3. 在左侧菜单底部进入 `Developer settings`。
4. 进入 `Personal access tokens`。
5. 推荐选择 `Tokens (classic)`。
6. 点击 `Generate new token`，再选择 `Generate new token (classic)`。
7. `Note` 可以填写 `捕捉计数器`，方便以后识别。
8. `Expiration` 按自己需要选择有效期；如果不想定期更换，可以选较长时间，但请妥善保管。
9. 在权限列表里只勾选 `gist`，不要勾选其它不需要的权限。
10. 点击页面底部的 `Generate token`。
11. 复制生成的 token，粘贴到网页里的 `GitHub Token` 输入框。

注意：Token 只会在 GitHub 生成后显示一次。如果忘记或丢失，不能查看原 token，只能删除后重新生成。

推荐流程：

1. 第一台设备填写 `GitHub Token`，`Gist ID` 留空。
2. 点击 `上传本机数据`。
3. 上传成功后复制保存生成的 Gist ID。
4. 第二台设备填写同一个 Token 和 Gist ID。
5. 点击 `拉取云端数据`。

注意：手动上传仍会用当前赛季本机数据覆盖当前赛季 Gist 文件。拉取会按当前赛季总抓取数保留更高版本；重大操作前仍建议先导出当前赛季 JSON 备份。S3 启用前，建议先导出一份 S2 备份。

### 赛季切换

S2 和 S3 数据分开保存。切换赛季会同时切换精灵列表、当前轮次、总体统计、自己获得记录、别人赠送记录、导入导出目标和同步文件。

- 切到 S2：查看和继续维护原有 S2 数据。
- 切到 S3：S3 启用后会加载 S3 默认精灵，计数和历史从 0 开始。
- 切换到 S3 不会删除、清空或覆盖 S2。
- 主题、GitHub Token 和 Gist ID 是全局设置，会在赛季之间共用。

### 当前轮次

默认折叠。展开后可以标记正在抓的精灵，并查看本轮仍有计数的精灵。

适合这种情况：你主要在刷精灵 A，但过程中也可能歪出 B、C。此时把 A 标记为“正在抓”，歪出时记录会写成抓 A 多少只时歪出。

- `正在抓`：当前目标精灵，用于判断和记录歪出。
- `本轮合计`：当前轮次里所有仍有本轮计数的精灵遭遇数总和。
- 精灵按钮：点击选择或取消本轮精灵。计数回到 0 后会自动移出。
- `更新本轮精灵`：只修改当前轮次包含哪些精灵，不清空计数。
- `开始新一轮并清零`：切换到新一轮，并清空所有精灵的本轮计数；历史遭遇不会清零。
- `清空本轮计数`：清空当前轮次中已选精灵的本轮计数；历史遭遇不会清零。

记录获得时：

- 如果选择“中了！”，系统会把当前轮次计数保存到这条获得记录里，并清空相关精灵的本轮计数。
- 如果选择“歪的”，系统会记录“抓目标精灵 N 只时歪出”，本轮所有精灵计数都不会改变。
- 历史遭遇数不会因为保存记录而清零。
建议：

- 继续刷同一个目标，只需要保持 `正在抓` 不变。
- 今天刷 A、明天改刷 B，建议先改 `正在抓`，必要时再用 `开始新一轮并清零`，避免不同目标的本轮数据混在一起。

### 总体统计

显示当前数据概况：

- 精灵数量
- 本轮遭遇
- 历史遭遇
- 自己获得记录数
- 别人赠送记录数

### 精灵列表

每个精灵卡片包含：

- `本轮`：当前这一轮的遭遇次数。
- `历史`：累计遭遇次数。
- `目标`：自定义目标次数。
- `+1`：本轮和历史各增加 1。
- `-1`：本轮和历史各减少 1，不会低于 0。
- `记录获得`：记录自己抓到或刷到该精灵。
- `记录赠送`：记录别人送给你的该精灵。
- `编辑`：修改名称和目标次数。
- `删除`：只会出现在自定义精灵上。删除后相关记录也会删除。

### 记录获得

点击 `记录获得` 后可以填写：

- 获得类型：`歪的` 或 `中了！`。如果获得的精灵不是正在抓的精灵，会默认选择 `歪的`。
- 时间：精确到秒。
- 备注：可选。

选择 `歪的` 保存后，本轮计数不会改变；选择 `中了！` 保存后，相关本轮计数会清零。保存后会出现在“获得历史”中。

### 记录赠送

点击 `记录赠送` 后可以填写：

- 精灵
- 时间：精确到秒
- 来源/赠送人
- 备注

赠送记录不会影响：

- 自己获得记录
- 本轮计数
- 历史遭遇
- 第几只统计


## 数据保存和安全

- 默认数据保存在当前浏览器的 `localStorage`，并按赛季分开保存。
- 清浏览器数据、换浏览器、换设备，都可能导致本地数据不可见。
- 重要数据建议定期使用 `导出 JSON` 备份；切换到新赛季前建议先导出 S2 备份。
- GitHub Token 属于敏感信息，只在自己的设备上填写，不要分享给别人。

## 常见问题

### 不配置多端同步能用吗？

能。同步是可选功能，本地计数不依赖账号。

### Gist ID 第一次不知道填什么？

第一次可以留空，只填 GitHub Token，然后点击 `上传本机数据`。上传成功后会自动保存 Gist ID。

### 点“拉取云端数据”会发生什么？

会比较当前赛季本机和云端总抓取数，并保留更高的版本。S2 和 S3 不会互相比大小，也不会互相覆盖。重大操作前仍建议先导出 JSON。

### 我昨天刷 A，今天刷 B，本轮应该怎么处理？

建议展开“当前轮次”，先把 `正在抓` 改成 B。如果不想保留上一轮本轮计数，再点击 `开始新一轮并清零`。

### 朋友送我的精灵要点“记录获得”吗？

不用。请点 `记录赠送`，这样不会影响自己的捕捉记录和遭遇统计。

### 切换到 S3 会清空 S2 吗？

不会。S2 和 S3 使用不同的本地存储 key、导出文件名和 Gist 文件名。S3 启用后会从 0 开始，S2 历史记录仍可切回查看。
