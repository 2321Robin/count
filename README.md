# S2 捕捉计数器使用说明

这是一个用于记录 S2 精灵遭遇次数、当前轮次进度、自己获得记录和别人赠送记录的网页计数器。应用默认把数据保存在当前浏览器本地；不登录、不配置同步也可以正常使用。

在线地址：http://count.w2321.top/

## 快速开始

1. 打开网页后，在精灵列表中找到要刷的精灵。
2. 每遭遇一次，点击对应精灵的 `+1`。
3. 点错时点击 `-1` 回退一次。
4. 自己抓到目标后，点击该精灵的 `记录获得`，填写时间和备注后保存。
5. 别人送给你的精灵，点击 `记录赠送` 单独记录。

## 页面区域

### 顶部操作

- `主题`：切换页面配色。默认是 `洛克幻想`，也可以选择 `深蓝夜航`、`霓虹赛季`、`森野薄荷`、`落日橙粉`、`纸白墨黑`。
- `新增精灵`：添加自定义精灵。

### 多端同步（可选）

默认折叠。不配置也不会影响本地使用。

如果只在一台设备使用，可以忽略这一栏。数据会保存在当前浏览器本地。

如果想在多台设备间同步，当前使用 GitHub 私密 Gist：

- `GitHub Token`：填写 GitHub Personal Access Token，只需要 `gist` 权限。
- `Gist ID`：第一次上传可以留空；上传成功后会自动保存。
- `上传本机数据`：把当前设备的数据上传到 Gist。会覆盖云端数据。
- `拉取云端数据`：把 Gist 中的数据拉到当前设备。会覆盖本机数据。
- `退出同步`：清除本机保存的 Token 和 Gist ID，不会删除本机计数数据。

获取 GitHub Token 的步骤：

1. 登录 GitHub。
2. 点击右上角头像，进入 `Settings`。
3. 在左侧菜单底部进入 `Developer settings`。
4. 进入 `Personal access tokens`。
5. 推荐选择 `Tokens (classic)`。
6. 点击 `Generate new token`，再选择 `Generate new token (classic)`。
7. `Note` 可以填写 `S2 捕捉计数器`，方便以后识别。
8. `Expiration` 按自己需要选择有效期；如果不想定期更换，可以选较长时间，但请妥善保管。
9. 在权限列表里只勾选 `gist`，不要勾选其它不需要的权限。
10. 点击页面底部的 `Generate token`。
11. 复制生成的 token，粘贴到网页里的 `GitHub Token` 输入框。

注意：Token 只会在 GitHub 生成后显示一次。如果忘记或丢失，不能查看原 token，只能删除后重新生成。

推荐流程：

1. 第一台设备填写 `GitHub Token`，`Gist ID` 留空。
2. 点击 `上传本机数据`。
3. 上传成功后复制保存生成的 Gist ID。
4. 第二台设备填写同一个 Token 和 Gist ID。
5. 点击 `拉取云端数据`。

注意：上传和拉取都是覆盖操作。拉取前建议先在“数据管理”里导出 JSON 备份。

### 当前轮次

默认折叠。展开后可以选择本轮一起统计的精灵。

适合这种情况：你主要在刷精灵 A，但过程中也会顺手记录 B、C。此时可以把 A、B、C 都选进“当前轮次”。

- `本轮合计`：当前轮次里所有已选精灵的本轮遭遇数总和。
- 精灵按钮：点击选择或取消本轮精灵。选中后会高亮。
- `更新本轮精灵`：只修改当前轮次包含哪些精灵，不清空计数。
- `开始新一轮并清零`：切换到新一轮，并清空所有精灵的本轮计数；历史遭遇不会清零。
- `清空本轮计数`：清空当前轮次中已选精灵的本轮计数；历史遭遇不会清零。

记录获得时：

- 如果获得的是当前轮次内的精灵，系统会把当前轮次内所有精灵的本轮计数合计保存到这条获得记录里。
- 同时保存每只精灵的明细。
- 保存后，当前轮次内这些精灵的本轮计数会清零。
- 历史遭遇数不会清零。

建议：

- 继续刷同一个目标，只用 `更新本轮精灵`。
- 今天刷 A、明天改刷 B，建议用 `开始新一轮并清零`，避免不同目标的本轮数据混在一起。

### 总体统计

显示当前数据概况：

- 精灵数量
- 本轮遭遇
- 历史遭遇
- 自己获得记录数
- 别人赠送记录数

### 精灵列表

每个精灵卡片包含：

- `本轮`：当前这一轮的遭遇次数。
- `历史`：累计遭遇次数。
- `目标`：自定义目标次数。
- `+1`：本轮和历史各增加 1。
- `-1`：本轮和历史各减少 1，不会低于 0。
- `记录获得`：记录自己抓到或刷到该精灵。
- `记录赠送`：记录别人送给你的该精灵。
- `编辑`：修改名称和目标次数。
- `删除`：只会出现在自定义精灵上。删除后相关记录也会删除。

### 记录获得

点击 `记录获得` 后可以填写：

- 时间：精确到秒。
- 备注：可选。

保存后会出现在“获得历史”中。

### 记录赠送

点击 `记录赠送` 后可以填写：

- 精灵
- 时间：精确到秒
- 来源/赠送人
- 备注

赠送记录不会影响：

- 自己获得记录
- 本轮计数
- 历史遭遇
- 第几只统计

### 数据管理

- `导出 JSON`：下载当前完整数据备份。
- `导入 JSON`：导入备份数据。旧版数据会自动兼容并升级。
- `清空所有数据`：删除所有精灵和记录，操作前会确认。
- `重置默认数据`：恢复默认精灵列表并清空记录，操作前会确认。

## 数据保存和安全

- 默认数据保存在当前浏览器的 `localStorage`。
- 清浏览器数据、换浏览器、换设备，都可能导致本地数据不可见。
- 重要数据建议定期使用 `导出 JSON` 备份。
- GitHub Token 属于敏感信息，只在自己的设备上填写，不要分享给别人。

## 常见问题

### 不配置多端同步能用吗？

能。同步是可选功能，本地计数不依赖账号。

### Gist ID 第一次不知道填什么？

第一次可以留空，只填 GitHub Token，然后点击 `上传本机数据`。上传成功后会自动保存 Gist ID。

### 点“拉取云端数据”会发生什么？

云端数据会覆盖当前设备的数据。拉取前建议先导出 JSON。

### 我昨天刷 A，今天刷 B，本轮应该怎么处理？

建议展开“当前轮次”，选择 B，然后点击 `开始新一轮并清零`。这样历史遭遇保留，但本轮重新开始。

### 朋友送我的精灵要点“记录获得”吗？

不用。请点 `记录赠送`，这样不会影响自己的捕捉记录和遭遇统计。
